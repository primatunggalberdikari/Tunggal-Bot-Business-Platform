# Catatan belajar Git

## 1. Apa yang saya pahami tentang Git ?
Github adalah sebuah tempat atau platform untuk sebuah proyek yang siap dideploy kesemua perangkat publik dan cloud tanpa harus update atau maintenance secara manual untuk masing-masing perangkat publik atau cloud, jadi upload, update atau maintenance sekali langsung menyebar kesemua perangkat dan cloud secara otomatis

## 2. Kenapa Git sangat penting untuk startup ?
Karena Git adalah platform yang sangat krusial didunia Industri digital terutama industri software dan para insinyur atau teknisi tidak perlu uplod kedalam cloud atau deploy berulang secara manual jadi mereka hanya melakukan testing, update atau maintenance didalam git tanpa harus melakukannya berulang disetiap cloud atau perangkat publik

## 3. Apa perbedaan git add dan git commit?
Git Add: hanya menandai folder file yang akan disimpan kedalam git commit
Git Commit: menyimpan file yang telah diubah oleh teknisi atau insinyur kedalam riwayat repository sebagai file baru

## 4. Apa itu repository?
Repository adalah sebuah folder proyek yang akan dibuat oleh para insinyur dan teknisi
