# Catatan Keamanan

## 1. Apa yang tidak boleh di-commit ke GitHub?
- Token BotFather
- Password
- API Key
- File .env
- Database (.db)

## 2. Mengapa token harus dirahasiakan?
Jika tidak dirahasiakan token akan jatuh ditangan yang salah pada pihak yang tidak bertanggung jawab

## 3. Bagaimana cara menyimpan rahasia dengan aman?
Memberi kode password atau pin, membuat template umpan, backup kedalam flashdisk atau disk lainnya
