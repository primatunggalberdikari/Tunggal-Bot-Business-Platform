# Catatan belajar Git

## Apa perbedaan folder User dan folder Project?
Folder user: sebuah folder dokumen yang berisi file dan dokumen pribadi milik user yang tidak boleh dipersebar luaskan
Folder project: sebuah folder dokumen yang berisi file dan dokumen proyek user yang bisa dikembangkan dan boleh dipersebar luaskan sesuai kebutuhan dan izin user

## Mengapa Git tidak boleh diinisialisasi di folder User?
karena folder file pribadi user akan menjadi file open source yang bisa ditiru oleh semua orang jika git dengan init folder user 

## Apa fungsi Personal Access Token?
sebagai password atau pintu izin pihak lain jika ingin memakai resource milik user dan pihak lain tidak bisa akses ataupun melihat resource milik user karena sudah terkunci layaknya password
